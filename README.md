## Live Site

Visit: [ivargavelin.com](https://ivargavelin.com)

## Features

- Interactive project filtering and search
- Sort by date or project scale
- Tech stack filtering
- Responsive design
- Pagination for easy browsing

## Tech Stack

- **Frontend**: HTML5, SCSS, JavaScript
- **Build Tool**: Parcel
- **Styling**: Bootstrap 4 + Custom SCSS
- **Animations**: ScrollReveal.js, Tilt.js

## Local Development

```bash
# Install dependencies
npm install

# Start development server
npm start

# Build for production
npm run build
```
